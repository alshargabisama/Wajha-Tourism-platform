# Wajha-Tourism-platform
A front-end tourism platform showcasing travel destinations with an interactive and responsive user interface.

## Overview

Wajha Tourism Platform is a front-end web application designed to promote tourism by showcasing destinations, attractions, and travel experiences through an interactive and user-friendly interface.

The project focuses on creating a clean, responsive, and engaging website using modern front-end web technologies without a backend or database.


## Features

- Modern and responsive user interface
- Interactive navigation
- Multiple web pages
- Dynamic functionality using JavaScript
- Organized project structure
- Clean and maintainable code


## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/alshargabisama/Wajha-Tourism-platform.git
```

### Open the project

Simply open the project folder and launch **index.html** in your browser.
